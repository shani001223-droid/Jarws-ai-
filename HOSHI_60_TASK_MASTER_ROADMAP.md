## Task 20 — offline screenshot OCR groundwork (26 Oct 2026; not yet accepted)
- Development-only implementation: `LocalScreenshotOcr.kt` uses a bundled, free on-device Google ML Kit Latin model. A user must explicitly choose a PNG/JPEG/WebP image in Android's document picker; there is **no background screen scraping, account interaction, screenshot upload or automatic AI submission**.
